# 小芽陪伴 第一版自主学习升级

面向4岁孩子与家长，延续绘本小熊、纸白和草木绿风格。孩子通过语音、图片点选、排序和格子互动完成每日学习，自动保存并打卡。

支持本机版和家庭在线版，不是手机安装包。本机启动方式不变；Render 家庭在线版提供家庭登录、服务端保存与跨设备正式学习记录同步，部署步骤见 [DEPLOY.md](DEPLOY.md)。每个在线部署只供一个家庭使用。

## 启动

打开 http://127.0.0.1:4318/ 。以后可双击“启动小芽.command”，保持窗口开启，再打开地址。也可在本目录运行：

```sh
python3 server.py
```

需要Python 3.9或更新版本，不需第三方依赖。已有数据库会继续使用，不会重新填入演示数据。

## 自主学习

| 方向 | 每日内容 | 互动 |
| --- | --- | --- |
| 英语 | 5单词＋5句子＋1场景故事 | 听词选图、句子配画面、三页故事互动 |
| 语文 | 5汉字＋5句子＋1生活场景 | 听音认图、句子理解、三页场景互动 |
| 数学思维 | 5个挑战 | 观察、分类、规律、数量对应、空间几何、顺序、逻辑、策略 |

家长选择每天学习哪些方向，所选方向每天都有。全部完成后自动打卡，不需要家长点击完成。运动由家长陪伴、独立记录，不影响自主学习打卡。

语言课地图显示11个单元，其中故事或生活场景有3页、每页有一次互动。语文的汉字、句子和生活场景题均使用汉字选项，场景顶部展示本课汉字；英语继续使用图片选项。单纯打开页面、播放语音或点击下一步不能跳过未完成的题。答错后可重试或请求提示；两次错误后主动显示提示。使用提示仍可完成，记录会区分无额外提示、提示后和重试后完成。

每一步均保存，包括排序题只做完一半的顺序。退出、刷新后从保存位置继续。没做完的课次下一次接着学，完成后才推进新课，漏一天不跳课，新计划也可延续之前课次。

已完成课程在学习地图和完成页提供“再来一次”，可以从第一题重新作答，包括提示、重试和数学排序。每轮复习使用独立进度，保存在当前浏览器，刷新或休息后可继续；完成后可再次开始。复习不修改数据库中的原始学习记录，不重复打卡、不推进课次，也不增加成长统计；复习进度不包含在数据库备份中。历史已完成课程也可复习，历史未完成课程仍仅供查看。

## 循序渐进

英语和语文各10个主题，每个主题先认识与体验，再辨认与理解，最后在更换后的图片、句子和场景中应用。之后安排巩固复习。每科有90个课次位置，包含复习，不代表90套全新故事。

数学逐步增加选项和条件，包含按两个条件分类、排除推理、排序和绕障碍选择第一步。成长回顾显示练习次数和参与过的思维方向，不给孩子能力评分。

英语自主课程默认直接播放随应用保存的206段预生成合成音频（微软 en-US-JennyNeural 美式女声，生成语速 -12%，与选定试听一致），覆盖全部英语单词、句子和故事文本，跨课复用相同音频。它们不是专业真人录音。播放不依赖浏览器的声音列表，音频已保存到本机；生成时仅向在线语音服务发送通用课程文本，不发送孩子档案和学习记录。普通播放保持原音速，“慢一点”使用保留音高的慢速播放。

中文课程、单字、数学语音和常用提示默认播放285段预生成的云夏音频（zh-CN-YunxiaNeural，生成语速 -12%，与选定试听一致）。中文的“长高、长大”按 zhǎng、比较字“长”按 cháng 使用限定同音替换处理，页面汉字保持原文。未覆盖的提示及未包含的英语活动使用设备语音合成，不申请麦克风。学习地图的“声音设置与试听”可选择中英文设备声音、试听及保存英文语速（仅当前浏览器）；英文选择“自动选择”时优先使用课程音频，手动选择设备声音则改用该声音。学习内容与中文题目分开播放，重复试听不再重复中文说明。切换页面、休息或应用进入后台会停止朗读。图示采用绘本插画和系统图形符号，外观随设备略有差异。

修改英语课程文本后，可运行 `uv run --with edge-tts python build_jenny_audio.py` 联网重建 Jenny 音频和映射。全部成功后才发布映射，失败可重试，已有音频会复用。首次加载 Jenny 版本会将旧英文设备声音和慢速偏好切回课程默认，后续家长仍可自行调整。预生成音频可在其他平台离线播放，不必重新生成。`build_english_audio.py` 保留为旧 Samantha 版本的生成工具。

内容尚未经专业幼教机构逐条审核，不是完整分龄教学课程，公开发布前仍需内容、语音、隐私与合规审核。

语文认字题的展示区仅放象形联想示意和代表图片，下方以现代汉字作答。“日、月、山、水、木”等16个字提供线条示意，其余字暂仅展示代表图片；图形为帮助联想的自绘示意，不是甲骨文、金文摹本，其他字暂不强配图。图文对照思路参考教育部有关教材介绍：https://www.moe.gov.cn/jyb_xxgk/xxgk_jyta/jyta_jiaocaiju/201912/t20191206_411056.html 。选择答案后先读出所选汉字，再播放反馈；答对后、回顾中可继续点击汉字重听，不重复作答或改变记录。单字发音默认使用选定的云夏音频。

## 档案和计划

保留昵称、四种头像、4岁0至11个月年龄选择及兴趣标签，不收集真实姓名或精确生日。当前只有一个孩子档案，兴趣标签不用于智能推荐。

周期支持7、14、21、30天预设以及1至90天自定义，可选今天或明天开始，开始后周期锁定。可提前结束本期并保留记录，再开始新计划；历史计划可在家长空间、日历和回顾中切换。

原有38个亲子活动保留，活动小屋用于亲子玩法预览；自主学习从首页进入。

## 旧计划升级

已有档案、亲子完成状态、观察和历史回顾全部保留。旧计划首页提供“设置自主学习”，由家长选择每日方向。

当天已有亲子完成记录时，新规则从下一天开始，避免改写当天打卡。启用前仍按原来的两项活动规则记录。新建计划默认启用自主学习。

## 记录与保存

日历区分完整打卡、部分参与、今天和未来；显示每科学习主题、阶段和单元数。未来不能提前打卡，历史学习仅供回顾，不补卡。

回顾显示学习课次、运动次数、词字和句子练习、故事场景、思维挑战、提示与重试。练习次数包含复习，不等于掌握的独立字词数量。家长可修改观察、撤销今日亲子活动；自主学习结果由真实互动生成，不提供一键手动完成。

数据保存在 `data/sprout.sqlite3`。刷新、关闭浏览器或重启服务后仍保留，不依赖浏览器缓存。服务只监听本机回环地址，不向局域网或互联网开放。同一电脑访问同一服务会看到同一家庭数据，没有多账户隔离。

家长空间可导出JSON备份、从文件恢复。恢复前额外导出当前数据副本，内容须通过格式和学习结果校验；旧版备份仍兼容。源码包不包含孩子数据。

保存使用事务和版本冲突检测。学习请求有唯一标识，网络重试不会重复计算错误或完成。失败不显示成功、不进入下一题，提供重试；另一页面修改数据时会提示重新读取。

内部保留最近30次写入前快照。升级前副本在 `data/before-autonomous-*.sqlite3`。日常使用应用导出的JSON备份，不要把运行中的SQLite单文件复制作为唯一备份。

## 验证与代码

```sh
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -v
```

测试覆盖5＋5＋1、故事三页、八类思维、阶段变化、提示与错误、排序部分保存、跨天延续、自动打卡、重复请求、旧规则兼容、数据库重开、备份和冲突。浏览器使用独立临时数据库验证三科整课、退出刷新、排序恢复、自动打卡和回顾联动，不混入正式数据。

- `server.py`：本机服务与SQLite事务。
- `learning.py`：服务端判题、顺序检查、课程延续、学习校验。
- `curriculum.json`：浏览器和服务端共用的版本化自主课程。
- `build_curriculum.py`：课程维护与生成源。
- `study-model.js`、`study-ui.js`、`study.css`：学习地图、互动、语音、重试、回顾。
- `model.js`、`app.js`：档案、计划、日历、记录和备份。
- `content.js`：原有亲子活动；`assets/`：小熊插画；`tests/`：自动化验证。

中文音频重建：`uv run --offline --with edge-tts python build_yunxia_audio.py`（组件需已缓存，生成音频需联网）。音频保存在本机，播放时无需联网；首次加载云夏版本会清除旧中文设备声音覆盖，不改变 Jenny 英文设置。

英语图片选项支持选后发音：先用 Jenny 读出所选图片对应的单词，再给中文反馈。适用于单词、句子和故事页；答对后和历史回顾中图片仍可点击重听，不重复作答或改变学习、打卡记录。全部90个课次的图片到单词映射均复用已有 Jenny 单词音频。

选后发音兼容性修正：正式学习在点击手势内立即启动单词音频，保存同时进行，确认保存且音频实际结束后再播放反馈。播放器在单词、反馈和重复试听之间复用；停止、切题或重听会取消过期反馈。脚本加载带版本标记，已有页面需刷新一次。

## 跟读闯关

英语、语文的每个单词／汉字、句子和故事／生活场景页，均在选对答案后进入跟读。听示范后点击“开始跟读”，浏览器语音识别返回最终文字，再由本机按目标内容计算0—100的“跟读匹配分”；达到80分才完成当前题、解锁继续和参与自动打卡。数学保持思维互动流程。

匹配分使用规范化文字的编辑距离，不评价音准、口音、流利度，不是专业发音评分；大小写、标点、中文数字表达和少数课程内单字同音识别变体做兼容。识别文字、分数、是否通过和次数随正式学习记录保存到SQLite，重复提交去重；复习仍保存在当前浏览器并保留原始打卡。既有完成步骤和历史打卡不作追溯清空，新未完成步骤与新复习采用跟读规则。日历学习记录显示跟读步数与平均匹配分。

首次使用需家长允许麦克风与语音识别。Web Speech API由浏览器提供，可能使用浏览器厂商的在线服务并发送音频，需要设备、语言、服务和网络支持。本应用不录制或保存音频，仅保存识别文字。页面说明见 https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition 。权限拒绝、没有听清、网络失败或浏览器不支持均显示实际原因，保持当前题，不能跳过跟读。切题、播放示范、离开页面或切到后台会停止识别，避免把示范音频当作孩子的回答。

自动化覆盖内容评分、选择后锁定、低分重试、达到阈值后继续、分数保存与数据库重开、网络重试去重、过期识别结果、权限失败及不支持环境。浏览器验证了真实页面的跟读入口与锁定状态；真实麦克风口述效果需家长在设备上试读确认，未用模拟识别结果作为真实试读通过记录。
